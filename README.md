# Stock Portfolio Tracker

A web app to track your stock portfolio with live prices.

## Built With
- Python + Flask
- JavaScript
- Bootstrap
- SQLite
- Yahoo Finance API (yfinance)

## Features
- Add stocks with live price
- Auto profit/loss calculation
- Refresh live prices anytime
- Search stocks
- Green/Red highlights

## How to Run
1. Install libraries:
   pip install flask yfinance

2. Setup database:
   python database.py

3. Run the app:
   python app.py

4. Open browser:
   http://localhost:5000"# stock-portfolio-tracker"
